Homework

Practice problems that never run out. Each kind of homework has its own page, its own difficulty levels, and instant feedback. Your progress is saved in this browser.

Assigning problems

Every problem has a short code. The same code always gives the same problem, so a tutor can set homework by sending a list of codes, and the student enters them in the "Load a code" box.

Sentence codes start with T (T2-k3j9a). Derivation codes start with a level number (2A-0-k3j9a).
