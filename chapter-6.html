Section 6.1

Mathematical induction

pp. 226–233 · exercises 6.1E

There are infinitely many sentences of SL, so no claim about all of them can be checked one at a time. Induction gets around this by sorting sentences into a series of groups (usually by number of connectives) and proving two things.

Basis clauseThe claim holds for every member of the first group, such as sentences with zero connectives.
Inductive stepIf the claim holds for every member of every group up to k (the inductive hypothesis), it holds for every member of group k + 1.

The book uses strong induction: the hypothesis covers all earlier groups, not just the previous one. Nothing is lost, since anything provable by weak induction is provable by strong induction.

The book's examples

First, that every sentence of SL has as many left as right parentheses. Then the dual of a TWA sentence (one using only ~, ∨ and &): swap ∨ and & and put a tilde in front of every atomic component. The thesis is that a TWA sentence and its dual always have opposite truth-values. The inductive step splits into cases by the main connective, which is the usual pattern.

Try the dual thesis

Type a sentence using only ~, ∨ and &. The dual is built and checked on every row.

Section 6.2

Truth-functional completeness

pp. 234–243 · exercises 6.2E

A truth-function of n arguments maps each combination of n truth-values to a truth-value. There are 2(2n) of them: 4 of one argument, 16 of two, 256 of three. SL's five connectives define only five, so it isn't obvious that SL can express them all.

Metatheorem 6.2.1Every truth-function can be expressed by a sentence of SL whose only connectives are ~, & and ∨. A set of connectives that can express every truth-function is truth-functionally complete.

The algorithm

  1. Use the first n sentence letters.
  2. For each row where the function's value is T, write an iterated conjunction that is true on exactly that row: the letter if it's T in that row, its negation if it's F.
  3. Disjoin those conjunctions. If no row is T, use a sentence that is false on every row instead.

Consequences: {~, ∨} is complete, since P & Q is equivalent to ~ (~ P ∨ ~ Q). So are {~, &} and {~, ⊃}. But {∨, &} is not: with no tilde you can never get F when every atom is T, which is a neat induction proof.

Section 6.3

The soundness of SD and SD+

pp. 244–251 · exercises 6.3E
Metatheorem 6.3.1If Γ ⊢ P in SD, then Γ ⊨ P.

The proof is by induction on line numbers in a derivation. The claim proved for each line i: the set Γi of open assumptions in whose scope the sentence Pi lies truth-functionally entails Pi.

  • Basis: the first line is an assumption, and {P1} ⊨ P1.
  • Inductive step: one case per rule. For each rule, if the cited lines are entailed by their open assumptions, the new line is entailed by its own. The subderivation rules need care, because they discharge an assumption.

Applied to the last line of a derivation of P from Γ, this gives Γ ⊨ P. Corollaries: every argument valid in SD is truth-functionally valid, and every theorem is truth-functionally true. SD+ is sound too, since its extra rules preserve entailment.

What soundness rules out

A rule like "from P ∨ Q, infer P" would let us derive non-entailed sentences, and the inductive step for it would fail: {P ∨ Q} doesn't entail P. Checking one case per rule is exactly what keeps a system honest.

Exercises 6.3E ask for the cases of the inductive step that the text leaves out.

Section 6.4

The completeness of SD and SD+

pp. 252–261 · exercises 6.4E
Metatheorem 6.4.1If Γ ⊨ P, then Γ ⊢ P in SD.

The proof is not constructive: it shows a derivation exists without saying how to build it. It follows Leon Henkin's 1949 method, which returns in Chapter 11 for predicate logic, where no constructive proof is available.

Key idea: a set that is maximally consistent in SD is consistent and can't take any new sentence without becoming inconsistent. For such a set, membership behaves just like truth: ~ P is in it exactly when P isn't, P & Q exactly when both are, and so on (6.4.11). So making its atoms true makes all its members true.

The chain of results

  1. 6.4.3If Γ ⊨ P, then Γ ∪ {~ P} is truth-functionally inconsistent.
  2. 6.4.2If a set is consistent in SD, it is truth-functionally consistent. (The hard part. By contraposition, Γ ∪ {~ P} is inconsistent in SD.)
  3. 6.4.4If Γ ∪ {~ P} is inconsistent in SD, then Γ ⊢ P: assume ~ P, derive Q and ~ Q, use ~E.
  4. 6.4.5Maximal Consistency Lemma. Every set consistent in SD has a maximally consistent superset. List all sentences of SL and add each one that keeps the set consistent.
  5. 6.4.8Consistency Lemma. Every maximally consistent set is truth-functionally consistent: make true exactly the atoms it contains.

Discussion questions
